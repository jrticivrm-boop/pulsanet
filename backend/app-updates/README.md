# Actualizaciones Android (APK en la app)

1. Copia `android.json.example` → `android.json` y ajusta `versionCode` / `versionName`.
2. Coloca la APK firmada en `files/` (ej. `TacticalPtx.apk`).
3. Reinicia la API si hace falta (lee el JSON en cada petición).
